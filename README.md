# Data-Science-tutorial

Introduction to Python and pandas with Afeez Sule.

All lesson examples and practice answers are in **Solutions.ipynb**. Keep **orders.csv** in the same folder.

## Setup

Install Python, Git, desktop VS Code, and the Microsoft **Python** and **Jupyter** extensions.

```bash
git clone https://github.com/Cyberpunk738/Data-Science-tutorial.git
cd Data-Science-tutorial
```

**Windows:**

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

**macOS / Linux:**

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

Open the folder in VS Code, open **Solutions.ipynb**, select **.venv** using **Select Kernel**, and run cells from top to bottom with **Shift+Enter**.

Dataset: [Tech With Tim’s PanadasTutorial](https://github.com/techwithtim/PanadasTutorial). The original CSV is unchanged.
